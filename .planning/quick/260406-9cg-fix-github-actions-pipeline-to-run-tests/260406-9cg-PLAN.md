Create `.github/workflows/ci.yml` with the following configuration:

**Triggers:**
- `push` to branches `main` and `master`
- `pull_request` to branches `main` and `master`

**Jobs:**

1. **test** job:
   - runs-on: `ubuntu-latest`
   - Steps:
     - `actions/checkout@v4`
     - Install stable Rust toolchain using `dtolnay/rust-toolchain@stable` with components: `clippy, rustfmt`
     - Cache cargo registry and target dir using `Swatinem/rust-cache@v2`
     - Run `cargo fmt --all -- --check` (formatting gate)
     - Run `cargo clippy --workspace --all-targets -- -D warnings` (lint gate)
     - Run `cargo test --workspace` (test gate)

Keep it as a single job so steps share the same cache and checkout. The sqlite crate has no rusqlite dependency yet, so no system-level libsqlite3-dev is needed.

Do NOT use `actions-rs` actions (unmaintained). Use `dtolnay/rust-toolchain` instead.
  </action>

  </verify>

  </done>
