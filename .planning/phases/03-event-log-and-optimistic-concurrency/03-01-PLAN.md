<objective>
Create the `EventLog<S: LogStore>` orchestrator and `EventLogError` error type in the `event-sourcing` core crate. EventLog is a thin wrapper that delegates to the underlying store while providing a stable user-facing API surface. The error mapping layer (`AppendError` -> `EventLogError`) establishes the extensibility point for Phase 6 (constraints) and Phase 7 (observers).

Purpose: Give callers a single entry point (`EventLog`) that decouples them from the storage layer, enabling future enrichment (constraints, observers, catch-up reads) without changing caller code.
Output: `event_log.rs` module with `EventLog<S>` and `EventLogError`, re-exported from crate root, with comprehensive tests covering all three requirements (LOG-04, LOG-05, LOG-06).
</objective>

       &self,
       stream_id: &StreamId,
       events: Vec<NewEvent>,
       condition: AppendCondition,
   ) -> Result<GlobalSequenceId, EventLogError> {
       self.store
           .append(stream_id, events, condition)

                   EventLogError::ConcurrencyConflict { stream_id, expected, actual }
