**InnerState** — Replace `HashMap<StreamId, Vec<StoredEvent>>` with flat vec:
```rust
struct InnerState {
    events: Vec<StoredEvent>,
    next_global_seq: u64,   // starts at 1
}

impl InnerState {
    fn new() -> Self {
        Self { events: Vec::new(), next_global_seq: 1 }
    }

    fn current_sequence(&self) -> GlobalSequenceId {
        if self.next_global_seq == 1 {
            GlobalSequenceId::ZERO
        } else {
            GlobalSequenceId::new(self.next_global_seq - 1)
        }
    }
}
```

**InMemoryLogStore** — Keep `Arc<RwLock<InnerState>>` pattern, `Clone`, `Default`:
```rust
pub type InMemoryEventStream = Iter<std::vec::IntoIter<Result<StoredEvent, StoreError>>>;

#[derive(Clone)]
pub struct InMemoryLogStore {
    inner: Arc<RwLock<InnerState>>,
}

impl Default for InMemoryLogStore {
    fn default() -> Self {
        Self { inner: Arc::new(RwLock::new(InnerState::new())) }
    }
}

impl InMemoryLogStore {
    pub fn new() -> Self { Self::default() }
}
```

**LogStore impl:**

`append`:
1. If `events.is_empty()`, return current_sequence under read lock (no-op).
2. Acquire write lock.
3. If `condition` is `Some(AppendCondition { query, after })`:
   - Scan `state.events` for any event where `event.global_sequence > after && event_matches_query(event, &query)`.
   - If found, return `Err(AppendError::ConcurrencyConflict { conflicting_position: found.global_sequence, checked_after: after })`.
4. For each `NewEvent`, create `StoredEvent` with next global_seq, copy `tags` from `NewEvent`, push to `state.events`.
5. Return last assigned `GlobalSequenceId`.

`query`:
1. Acquire read lock.
2. Filter `state.events` where `event.global_sequence >= from && event_matches_query(event, &query)`.
3. Clone matching events, wrap in `Ok`, collect to `Vec`.
4. Drop lock, return `stream::iter(results)`.

`current_sequence`:
1. Acquire read lock, return `state.current_sequence()`.
