<objective>
Revise the `projection!` macro parser to implement the Phase 4.1 DSL syntax.

Purpose: The Phase 4 syntax has two ergonomic problems — a redundant inner `projection` keyword requiring double-nesting, and object fields that use inconsistent syntax (`field? { }` vs `field?: value`). This plan fixes the parser to enforce the cleaner, consistent Phase 4.1 syntax.

Output: A revised `projection_macro.rs` where `ProjectionInput::parse` and `parse_field_decl` enforce: no wrapping braces or inner keyword, comma field separators, unified `:` before `{` for objects, and compile-time `cleared_by` rejection on non-nullable objects.
</objective>

**Change 1: ProjectionInput::parse — remove inner `projection` keyword**

NEW start (caller invokes `projection! Name { ... }` — the macro name IS the keyword):

```rust
fn parse(input: ParseStream) -> Result<Self> {

    let name: Ident = input.parse()?;
```

The `braced!(body in input);` line stays. The query parsing stays. Only the `input.parse::<projection>()?;` line is removed.

**Change 2: Field loop — add comma separator parsing**


NEW:

**Change 3: parse_field_decl — unify `:` syntax for both scalars and objects**

Replace the field type detection block. OLD logic:
```rust
// Check if this is an object block `{ ... }` or a scalar `:`
if input.peek(token::Brace) {
    // Object: name? { ... }
    ...
} else {
    // Scalar: name: handler
    input.parse::<Token![:]>()?;
    ...
}
```

NEW logic (always parse `:` first, then peek for Brace to decide):
```rust
// Phase 4.1: always parse `:` after name (and optional `?`)
// Grammar: name [?] : ({ sub_fields } | handlers)
input.parse::<Token![:]>()?;

// Check if this is an object block `{ ... }` or scalar handlers
if input.peek(token::Brace) {
    // Object field: `name: { sub_fields } [cleared_by alias.Event]`
    //           or  `name?: { sub_fields } [cleared_by alias.Event]`
    let sub_body;
    braced!(sub_body in input);

    let mut sub_fields = Vec::new();
    while !sub_body.is_empty() {
        sub_fields.push(parse_scalar_field_decl(&sub_body, alias)?);
        // Consume optional trailing comma between sub-fields
        if sub_body.peek(Token![,]) {
            sub_body.parse::<Token![,]>()?;
        }
    }

    // Optional `cleared_by alias.EventType`
    let cleared_by_event = if input.peek(cleared_by) {
        // Compile-time enforcement: cleared_by only valid on nullable objects
        if !optional {
            return Err(Error::new_spanned(
                &name,
                "cleared_by requires a nullable object field (use `field?: { ... }` instead of `field: { ... }`)",
            ));
        }
        input.parse::<cleared_by>()?;
        let cb_alias: Ident = input.parse()?;
        if cb_alias != *alias {
            return Err(Error::new_spanned(
                &cb_alias,
                format!(
                    "cleared_by alias `{}` does not match query alias `{}`",
                    cb_alias, alias
                ),
            ));
        }
        input.parse::<Token![.]>()?;
        let event_type: Ident = input.parse()?;
        Some(event_type.to_string())
    } else {
        None
    };

    Ok(FieldDecl::Object {
        name,
        optional,
        sub_fields,
        cleared_by_event,
    })
} else {
    // Scalar field: `name: handler [| handler]*`
    let handlers = parse_handlers(input, alias)?;
    Ok(FieldDecl::Scalar {
        name,
        optional,
        handlers,
    })
}
```

Note: the `Error::new_spanned(&name, ...)` for `cleared_by` on non-nullable uses `&name` (the field name Ident) as the span target. This requires `name` to be bound before the check — which it is, since `name: Ident = input.parse()?` happens at the start of `parse_field_decl`.
