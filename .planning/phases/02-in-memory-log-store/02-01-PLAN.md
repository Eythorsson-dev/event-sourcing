**Struct layout** (per D-03 — Arc-backed interior, clone shares state):
```rust
use std::collections::HashMap;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::Arc;
use std::time::SystemTime;

use event_sourcing::{
    AppendCondition, AppendError, GlobalSequenceId, LogStore, NewEvent,
    StoredEvent, StoreError, StreamId, StreamSequenceId,
};
use futures::stream::{self, Iter};
use tokio::sync::RwLock;

type InMemoryEventStream = Iter<std::vec::IntoIter<Result<StoredEvent, StoreError>>>;

#[derive(Clone)]
pub struct InMemoryLogStore {
    inner: Arc<RwLock<InnerState>>,
    next_seq: Arc<AtomicU64>,
}

struct InnerState {
    streams: HashMap<StreamId, Vec<StoredEvent>>,
}
```

**Default impl** — initializes empty state with sequence counter at 0:
```rust
impl Default for InMemoryLogStore {
    fn default() -> Self {
        Self {
            inner: Arc::new(RwLock::new(InnerState {
                streams: HashMap::new(),
            })),
            next_seq: Arc::new(AtomicU64::new(0)),
        }
    }
}

impl InMemoryLogStore {
    pub fn new() -> Self {
        Self::default()
    }
}
```

**LogStore impl** — all 5 methods with native `async fn` (no `async-trait`):

1. **`append`**: For each `NewEvent` in the vec:
   - Allocate global seq via `self.next_seq.fetch_add(1, Ordering::SeqCst) + 1` (1-based per Phase 1 D-06)
   - Acquire write lock on `self.inner`
   - Check `AppendCondition::ExpectedVersion(expected)`: compare `expected` against current stream length (`StreamSequenceId::new(stream_vec.len() as u64)`). If mismatch, return `AppendError::ConcurrencyConflict { stream_id, expected, actual }`.
   - For `AppendCondition::Any`: skip version check.
   - Compute `stream_sequence = StreamSequenceId::new(stream_vec.len() as u64 + 1)` (1-based)
   - Construct `StoredEvent` with `SystemTime::now()` timestamp (per Phase 1 D-09)
   - Push to `streams.entry(stream_id.clone()).or_default()`
   - Return `Ok(last_global_sequence_id)` — the global seq of the last event appended

   IMPORTANT: The version check must happen ONCE before appending any events, using the stream length before the batch. All events in the batch share the same expected-version check. Global sequence must be allocated per-event (each event gets its own monotonic ID). Acquire the write lock FIRST, then allocate sequence IDs while holding it — this ensures no gap between version check and sequence allocation.

   Correction to research pattern: allocate global seq INSIDE the write lock to prevent a race where two concurrent appends both allocate sequences but then one fails the version check, leaving a gap. The `AtomicU64` approach from research works for `AppendCondition::Any` but creates sequence gaps on `ConcurrencyConflict`. Simpler correct approach: keep `next_global_seq: u64` inside `InnerState` and increment under the write lock.

   Revised inner state:
   ```rust
   struct InnerState {
       streams: HashMap<StreamId, Vec<StoredEvent>>,
       next_global_seq: u64, // starts at 1; incremented under write lock
   }
   ```
   Remove the `AtomicU64` field from `InMemoryLogStore`. Initialize `next_global_seq: 1` in `Default`.

2. **`read_stream`**: Acquire read lock. Get `streams.get(stream_id)`. If `None`, return `Ok(stream::iter(vec![]))` (per D-04 — empty, not error). Filter events where `stream_sequence >= from` and (if `to` is Some) `stream_sequence <= to`. Clone into `Vec<Result<StoredEvent, StoreError>>`, drop lock, return `Ok(stream::iter(events))`.

3. **`read_all`**: Acquire read lock. Collect ALL events from ALL streams into a single `Vec<StoredEvent>`. Sort by `global_sequence`. Filter where `global_sequence >= from`. Clone into `Vec<Result<StoredEvent, StoreError>>`, drop lock, return `Ok(stream::iter(events))`.

4. **`current_sequence`**: Acquire read lock. Return `GlobalSequenceId::new(self.inner.read().await.next_global_seq - 1)`. If `next_global_seq == 1` (no events), return `GlobalSequenceId::ZERO`.

5. **`stream_version`**: Acquire read lock. Get `streams.get(stream_id)`. If `None`, return `Ok(StreamSequenceId::ZERO)`. Otherwise return `StreamSequenceId::new(vec.len() as u64)`.

CRITICAL constraints:
- Do NOT hold the RwLock guard across any `.await` point. Acquire, do sync work, drop, then return.
- Do NOT use `async-trait` — use native `async fn` syntax per D-01.
- The `EventStream` associated type is `Iter<std::vec::IntoIter<Result<StoredEvent, StoreError>>>`.
- All events in a batch must be appended atomically — either all succeed (version check passes) or none do (version check fails).
