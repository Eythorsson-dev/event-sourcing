## TagFilter JSON Format

Each variant uses serde's default externally-tagged format:

| Variant | Example JSON |
|---------|-------------|
| Equals | `{"Equals":"order:o1"}` |
| StartsWith | `{"StartsWith":"order:"}` |
| EndsWith | `{"EndsWith":":o1"}` |
| And | `{"And":[{"Equals":"a"},{"Equals":"b"}]}` |
| Or | `{"Or":[{"StartsWith":"premium:"},{"EndsWith":":vip"}]}` |

GlobalSequenceId serializes as a bare number via `#[serde(transparent)]`: `42`
