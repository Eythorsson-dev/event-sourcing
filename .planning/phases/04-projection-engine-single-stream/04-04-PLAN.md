```rust
    /// Incremental fold from an optional checkpoint.
    /// checkpoint=None means full replay from scratch.
    pub fn project_from<M: ReadModel>(

    ) -> Result<(M, ProjectionCheckpoint), ProjectionError>;
```

Fold semantics (from CONTEXT.md D-17 through D-29):
- Start with initial state = `serde_json::Value::Object(Map)` with all fields set to their `default` value if present, otherwise `null`.
- For each `StoredEvent` in sequence order:
  - Look up the event_type in each top-level FieldSpec's `events` map (ScalarFieldSpec) or each nested ObjectFieldSpec's nested fields.
  - Apply the HandlerSpec:
    - `From { from }`: evaluate the JSON path against `event.payload`, set the field to the resolved value.
    - `Value { value }`: set the field to the literal value.
    - `Increment { increment }`: add `increment` to the current numeric field value.
    - `Decrement { decrement }`: subtract from numeric field.
    - `IncrementBy { increment_by }`: evaluate path, add the resolved numeric to current.
    - `DecrementBy { decrement_by }`: evaluate path, subtract.
  - For ObjectFieldSpec: if the event_type is in `cleared_by`, set the entire object to `null`.
  - Skip events not referenced in any handler (D-22).

    ```rust
    use serde_json::{Map, Value};
    use serde_json_path::JsonPath;

    /// Evaluate an RFC 9535 JSON Path expression against a serde_json::Value payload.
    /// Returns the first matching node, or None if no match.
    ///
    /// Callers (the builder) guarantee that `path` is a valid JsonPath string —
    /// `unwrap()` here is safe because invalid paths are rejected at definition-build time.
    pub(crate) fn evaluate_path(payload: &Value, path: &str) -> Option<Value> {
        let compiled = JsonPath::parse(path).ok()?;
        compiled.query(payload).first().cloned()
    }
    ```

    Using `serde_json_path` instead of a hand-rolled evaluator:
    - Full RFC 9535 compliance — paths like `$.field`, `$.nested.field`, `$[0]`, `$[*]` all work correctly.
    - Future phases (4.1 list fields, 5 joins) that need array traversal or wildcards get them for free.
    - The builder (plan 04-02) already validates paths at definition-construction time, so `JsonPath::parse()` in the engine will not fail for correctly-built definitions.

    Tests for `evaluate_path`:
    - `path_simple_field`: `{"amount": 42}` + `"$.amount"` → `Some(Value::Number(42))`.
    - `path_nested`: `{"address": {"city": "London"}}` + `"$.address.city"` → `Some(Value::String("London"))`.
    - `path_missing_field`: `{"x": 1}` + `"$.y"` → `None`.
    - `path_null_value`: `{"name": null}` + `"$.name"` → `Some(Value::Null)`.
    - `path_invalid_expression`: a malformed path string (e.g. `"not-a-path"`) → `None` (parse fails, `ok()?` short-circuits).

    Note: there is no `path_no_dollar_prefix` test — `serde_json_path` requires the standard `$.` prefix per RFC 9535. The builder enforces this at construction time.

    ```rust
    use crate::projection::definition::{
        FieldSpec, HandlerSpec, ObjectFieldSpec, ProjectionDefinition, ScalarFieldSpec,
    };
    use crate::projection::error::ProjectionError;
    use crate::types::GlobalSequenceId;
    // StoredEvent — use the actual path from event.rs

    pub trait ReadModel: serde::de::DeserializeOwned {
        fn definition() -> ProjectionDefinition;
    }

    pub struct ProjectionCheckpoint {
        pub(crate) raw_state: Value,
        pub(crate) last_sequence: GlobalSequenceId,
    }

    pub struct ProjectionEngine;

    impl ProjectionEngine {
        pub fn apply_raw(
            def: &ProjectionDefinition,
            events: impl Iterator<Item = StoredEvent>,
        ) -> Result<Value, ProjectionError> {
            // 1. Build initial state: Object with all field keys set to their default or null.
            let mut state = Value::Object(Map::new());
            Self::initialize_state(def, &mut state);

            // 2. Fold each event.
            for event in events {
                Self::apply_event(def, &event, &mut state)?;
            }
            Ok(state)
        }

        pub fn project<M: ReadModel>(
            events: impl Iterator<Item = StoredEvent>,
        ) -> Result<M, ProjectionError> {
            let def = M::definition();
            let raw = Self::apply_raw(&def, events)?;
            Ok(serde_json::from_value(raw)?)
        }

        pub fn project_from<M: ReadModel>(
            checkpoint: Option<ProjectionCheckpoint>,
            new_events: impl Iterator<Item = StoredEvent>,
        ) -> Result<(M, ProjectionCheckpoint), ProjectionError> {
            let def = M::definition();
            let mut state = match checkpoint {
                Some(cp) => cp.raw_state,
                None => {
                    let mut s = Value::Object(Map::new());
                    Self::initialize_state(&def, &mut s);
                    s
                }
            };
            let mut last_sequence = GlobalSequenceId::default(); // or 0
            for event in new_events {
                last_sequence = event.global_sequence;
                Self::apply_event(&def, &event, &mut state)?;
            }
            let model: M = serde_json::from_value(state.clone())?;
            Ok((model, ProjectionCheckpoint { raw_state: state, last_sequence }))
        }
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| StoredEvent payload → engine fold | Event payloads (serde_json::Value) from storage used as data source; may contain unexpected shapes |
| ProjectionDefinition → engine | Caller-supplied definition drives fold logic; path expressions evaluated against payload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.04-01 | Tampering | JSON path evaluation | mitigate | evaluate_path only traverses Object nodes, returns None for unexpected types (arrays, primitives mid-path). FieldNotFound error is returned rather than silently producing wrong output. Tested by path tests. |
| T-04.04-02 | DoS | Deeply nested ProjectionDefinition or payload | accept | No recursion depth limit in Phase 4. Practical depth is bounded by the projection schema (authored by the library user). Arrays in payloads not supported — limits accidental blowup. |
| T-04.04-03 | Information Disclosure | ProjectionError::FieldNotFound leaks path info | accept | Errors contain field paths and event types — these are internal library debug info, not secrets. Callers choose whether to expose these errors to users. |
| T-04.04-04 | Tampering | Increment/Decrement on non-numeric field | mitigate | TypeMismatch error returned on non-numeric value; no silent corruption. Tested by increment test. |
</threat_model>
